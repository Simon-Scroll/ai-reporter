# Assignment

## Question

Can OPM's public Federal Workforce Data site support comparable government-wide workforce and administrative-leave measures when OPM's own release notes identify missing components and historical reporting limitations?

## Scope

This is a document comparison, not an accusation about individual employees or agencies. The initial work compares GAO-26-108477 with OPM's current release notes, data-quality page, data-sources page, dashboard source notes, and API metadata. A publishable result requires a specific reproducible mismatch or a documented negative finding that the public denominator is adequately disclosed.

## Selection

- Public interest: 5/5
- Originality: 3/5 after the GAO report and current OPM records were excerpted
- Document-nativeness: 5/5
- Room to grow: 5/5
- Legal risk: 1/5
- Net: 17/25

The lead is not a GAO recap: the work tests whether current OPM disclosures and public data endpoints permit a comparable measurement.
