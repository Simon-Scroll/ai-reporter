## Excerpts

- Release 1.14.0: June 2026 Status data was re-published with 77,743 missing Department of War records, with approximately 6,211 records still missing from named components; July 2026 Dynamics files from provider DD07 remained missing.
- Release 1.15.0: OPM updated data standards and identifiers but did not state that the missing June/July components had been fully restored.
- The current page banner says a change in Department of War data processing prevented some components from submitting June and July 2026 data; most data had been received, with some components still outstanding.

## Why it matters

OPM's own current release record supplies a second primary source showing that public EHRI completeness is an active, dated issue. The record does not by itself show how a particular dashboard metric changes.
