# Adversarial review — 2026-10-03

## Claims that survive

- The $507 million FY2027 Pearl Harbor Dry Dock 3 Replacement line is supported by the Navy's FY2027 Budget Highlights Book, Figure 4.2. The six-line sum is explicitly labeled as a desk calculation, not a Navy-reported SIOP total.
- USAspending directly joins PIID N62742-23-F-4007 to “FY23 MCON PROJECT P-209, DRY DOCK 3 REPLACEMENT, JOINT BASE PEARL HARBOR HICKAM, HAWAII.” The reported obligation, option, and performance-end values match the captured API response.
- The comparison is a same-object comparison: both records identify the Pearl Harbor Dry Dock 3 project, while measuring a budget-year request and an execution award differently.
- H. Rept. 119-622 supports the Navy and Marine Corps recommendation amount and the future NAVFAC/NAVSEA SIOP waterfront-facility report direction. Congress.gov supports that H.R. 8800 was passed by the House and received in the Senate, not enacted.
- The current NAVFAC PEO IE page supports the $6.3 billion ongoing-work figure and describes an integrated cost, schedule, and risk-management framework. It does not state that $6.3 billion is a full-program cost.
- The draft labels the interpretive conclusion and expressly rejects claims of delay, waste, misconduct, or overrun.

## Claims that die or require narrowing

- “The matching execution object” is acceptable only because the USAspending description names P-209, Dry Dock 3 Replacement, and the Pearl Harbor installation. Do not use the NAVFAC page's “Dry Dock 5” heading as proof of a discrepancy; the draft does not do so.
- “The $507 million line is not the project’s public execution total” is an inference from unlike measures. It must remain labeled as inference and must not be phrased as a cost increase, overrun, or mismatch.
- “The public documents do not provide one current table” is a bounded absence claim. It is supported by the captured comparison, but should not be generalized to the Navy's nonpublic internal records.
- The $6.3 billion NAVFAC figure is a work-in-progress measure, not a new denominator. Do not compare it arithmetically with the $1.8 billion FY2027 request or the P-209 award values.

## Remaining gaps

- The record does not expose the full cross-appropriation composition of the $1.8 billion SIOP headline or a lifecycle baseline for all six FY2027 lines.
- H.R. 8800's House-passed text is not enacted, and the directed House report is prospective. Do not describe either as binding current law or as a completed reconciliation.
- The fresh official-record check found no enacted FY2027 authorization or completed directed report. The current NAVFAC page adds program-management context but does not close the baseline gap.

## Recommendation

**Publish.** The comparison is original enough to publish and is not a single-document recap. The fresh official-record check did not change the bounded same-object comparison. Publish only the labeled traceability gap, with the current NAVFAC figure clearly identified as ongoing work rather than a total program cost, after `npm run validate` passes.
