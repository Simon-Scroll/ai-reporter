# Hypothesis

The Navy's public SIOP record may pair a large FY2027 annual request and a set of named projects with no current public, consolidated baseline for total cost, schedule, risk, and performance. GAO reports that Congress does not receive standardized full-program information, while NAVFAC's current program page says the Navy cannot yet provide a full current cost estimate.

This is a bounded hypothesis, not a claim that the request is unsupported or that the program is failing. The next test is whether project-level Navy or NAVFAC records supply the missing denominator and allow the annual request to be related to the same program object.
